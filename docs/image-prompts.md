# RDM image prompts (Google Gemini)

Each prompt is complete and ready to copy. Generate #1 first, then attach it as a reference image
to the others for a consistent car. The RDM logo is added afterwards — the prompts ask for no text.

Design language: Polish retro-futurism — the angular 1970s–80s FSO Polonez wedge and the 1960 Syrena Sport
concept, reimagined for 2026.
